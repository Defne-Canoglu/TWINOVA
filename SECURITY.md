# Security and deployment scope

The demonstration server binds to loopback and has no authentication. Run it locally. Before network deployment, add an authenticated application gateway, TLS, request limits and an appropriate data-access policy.

Python joblib model files can execute code while loading. Load only trusted, integrity-checked models. Do not commit credentials, patient records, identifiable astronaut records, serial capture logs or environment files. The bundled cohort is an engineering dataset described in the model card.

Report a suspected issue privately to the repository owner through the GitHub reporting channel when configured. Do not publish credentials or personal data in public issues.
